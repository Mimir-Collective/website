LIBRARIES

Open-source ZK circuits, built in public on GitHub, anyone can read, use, and build on them.

noir-sparse-merkle

A Sparse Merkle Tree circuit for Noir that proves a key either belongs to, or is absent from, a committed tree root. Supports membership (∈) and non-membership (∉) proofs in one interface, built for proof of innocence.

poseidon2-interop-kit

An open-source Poseidon2 kit that standardizes hashing across Noir, Rust, and Solidity for privacy systems using sparse Merkle trees and note/nullifier flows. Correctness, compatibility, and developer ergonomics, not a new primitive.

noir-nullifier

A ZK spend circuit for Noir that proves note ownership and prevents double-spends without revealing which note is being spent. Combines commitment membership and nullifier non-membership proofs in one composable interface.
